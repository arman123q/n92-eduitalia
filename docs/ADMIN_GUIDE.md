# N92 Edu-Italia — Admin Guide (day-to-day use)

Log in at **/admin** on your website with your admin email and password.
Everything you save here updates the live website — no developer needed.

## Dashboard
Your real numbers: total enquiries, new leads, leads needing follow-up,
published records, and scholarships that still need a verification check.
Nothing here is estimated or decorative.

## Student Leads
- New website enquiries arrive here automatically (status **New**).
- Open a lead to see the student's details, their message and — when they
  came from the eligibility check — their assessment summary.
- Change **status** as you work: New → Contacted → Follow-up Required →
  Consultation Booked → Closed. Set a **follow-up date** and add
  **internal notes** (students never see these). Changes save
  automatically.
- **Export CSV** downloads the filtered list (for Excel/Sheets).
- **Retention:** delete enquiries you no longer need (for example, closed
  enquiries older than 24 months, or immediately when a student asks).
  Deletion is permanent. This is a routine, not legal advice — if you are
  unsure about a request from a student about their data, get advice
  before deleting or sharing it.

## Universities / Courses / Scholarships / FAQs
- **Add** with the "+ Add" button; **Edit** any row; **Delete** asks for
  confirmation first.
- New records start as **Draft** — invisible to the public. Press
  **Publish** when the record is ready; **Unpublish** hides it again.
- Courses must be linked to a university (dropdown in the form).
- **Verification status** matters: only mark a record **Verified** after
  you have personally opened its official source page and checked the
  details. "Needs review" shows a public warning label — that honesty is
  deliberate.
- Fees and deadlines: type only what the official page states. If you
  don't know, write "Not verified" — the website displays that honestly.
- Every edit keeps an automatic snapshot, and admin actions are written
  to an audit log.

## Website Content
- Edit the **homepage hero text** and turn homepage **sections on/off**.
- **Save draft** = private. **Publish now** = live. Publishing keeps the
  previous live version in the rollback list below — **Restore as draft**
  brings it back for review before you publish it again.

## Calculator Settings
Change the calculator's starting numbers (rent, food, transport, permit,
exchange rate…). Students can adjust every figure themselves; your
settings are only the starting point. Keep the rate date honest.

## Media Library
Upload images (max 5 MB), copy their URL to use in content, delete with
care — deleting an image that a page uses will break that image until
the page is updated.

## FAQs & the Guidance Assistant
The chat assistant on the website answers **only** from published FAQs —
edit or unpublish an FAQ and its answers change accordingly. It never
invents answers; unknown questions are routed to your WhatsApp.

## If you forget your password
On the login screen, enter your admin email and tap the reset link —
Supabase emails you a password-reset link.
